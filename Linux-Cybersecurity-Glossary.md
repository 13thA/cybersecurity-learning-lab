# CYBERSECURITY ENGLISH GLOSSARY

# 1. TEMEL LINUX & TERMINAL

### 1. Shell

**Türkçe:** Kabuk
**Siber güvenlikte:** Kullanıcı ile işletim sistemi arasında komutları yorumlayan arayüz.
**Kullanım:** Bash, Zsh gibi shell'lerde.
**Örnek:** `The shell interprets the command.`

### 2. Terminal

**Türkçe:** Terminal
**Siber güvenlikte:** Komut satırına erişmek için kullanılan arayüz.
**Kullanım:** Linux yönetimi ve güvenlik araçları.
**Örnek:** `Open the terminal and run the command.`

### 3. Command

**Türkçe:** Komut
**Siber güvenlikte:** Sisteme belirli bir işlem yaptıran ifade.
**Kullanım:** Linux ve Windows komut satırı.
**Örnek:** `Run the command as root.`

### 4. Command Line

**Türkçe:** Komut satırı
**Siber güvenlikte:** Sistemi metin tabanlı komutlarla yönetme yöntemi.
**Kullanım:** Linux, Windows, otomasyon.
**Örnek:** `The tool can be used from the command line.`

### 5. CLI

**Türkçe:** Komut satırı arayüzü
**Siber güvenlikte:** Grafik arayüz yerine komutlarla çalışan arayüz.
**Kullanım:** Güvenlik araçları ve sistem yönetimi.
**Örnek:** `This security tool has a CLI.`

### 6. Prompt

**Türkçe:** Komut istemi
**Siber güvenlikte:** Terminalin kullanıcıdan komut beklediğini gösteren bölüm.
**Kullanım:** Shell.
**Örnek:** `The prompt shows the current user.`

### 7. Directory

**Türkçe:** Dizin
**Siber güvenlikte:** Dosyaların bulunduğu filesystem yapısı.
**Kullanım:** Linux dosya sistemi.
**Örnek:** `The log files are stored in this directory.`

### 8. Folder

**Türkçe:** Klasör
**Siber güvenlikte:** Dosyaları organize eden klasör.
**Kullanım:** Genel kullanım.
**Örnek:** `Create a new folder for the logs.`

### 9. Path

**Türkçe:** Yol
**Siber güvenlikte:** Bir dosya veya dizinin filesystem üzerindeki konumu.
**Kullanım:** Linux, Windows.
**Örnek:** `Check the file path.`

### 10. Root

**Türkçe:** Kök / root kullanıcısı
**Siber güvenlikte:** Linux'taki en yüksek yetkili kullanıcı veya `/` kök dizini.
**Kullanım:** Sistem yönetimi.
**Örnek:** `The root user has extensive privileges.`

### 11. Home

**Türkçe:** Ev dizini
**Siber güvenlikte:** Kullanıcının kişisel dosyalarının bulunduğu dizin.
**Kullanım:** Linux.
**Örnek:** `The configuration file is in the user's home directory.`

### 12. Current Directory

**Türkçe:** Mevcut dizin
**Siber güvenlikte:** Terminalde o anda bulunduğun dizin.
**Kullanım:** Linux komutları.
**Örnek:** `Use pwd to display the current directory.`

### 13. Working Directory

**Türkçe:** Çalışma dizini
**Siber güvenlikte:** Bir programın veya shell'in o anda çalıştığı dizin.
**Kullanım:** Linux ve scripting.
**Örnek:** `The script uses the current working directory.`

### 14. Absolute Path

**Türkçe:** Mutlak yol
**Siber güvenlikte:** `/` kökünden başlayan tam dosya yolu.
**Kullanım:** Linux filesystem.
**Örnek:** `/home/user/file.txt` is an absolute path.

### 15. Relative Path

**Türkçe:** Göreli yol
**Siber güvenlikte:** Mevcut konuma göre belirtilen dosya yolu.
**Kullanım:** Linux ve scripting.
**Örnek:** `Use a relative path to access the file.`

### 16. Argument

**Türkçe:** Argüman
**Siber güvenlikte:** Komuta verilen değer veya hedef.
**Kullanım:** Linux komutları.
**Örnek:** `The filename is passed as an argument.`

### 17. Option

**Türkçe:** Seçenek
**Siber güvenlikte:** Komutun davranışını değiştiren parametre.
**Kullanım:** CLI.
**Örnek:** `Use the -a option.`

### 18. Flag

**Türkçe:** Bayrak / seçenek
**Siber güvenlikte:** Komuta belirli bir davranış kazandıran kısa seçenek.
**Kullanım:** CLI.
**Örnek:** `The -l flag displays detailed information.`

### 19. Manual

**Türkçe:** Kılavuz
**Siber güvenlikte:** Bir Linux komutunun kullanım belgeleri.
**Kullanım:** `man` komutu.
**Örnek:** `Read the manual before using the command.`

### 20. Environment

**Türkçe:** Ortam
**Siber güvenlikte:** Programların çalıştığı sistem ve değişkenler bütünü.
**Kullanım:** Linux ve scripting.
**Örnek:** `Check the environment before running the script.`

### 383. Determine

**Türkçe:** Belirlemek

### 386. Prevent

### 387. Respond

### 388. Recover

**Türkçe:** Kurtarmak / normale döndürmek
**Siber güvenlikte:** Olaydan sonra sistemleri normal çalışmaya döndürmek.

### 389. Collect

**Türkçe:** Toplamak
